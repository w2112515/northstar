# NorthStar（北极星）— 产品定义

> 状态：v1，2026-08-30。本文件是产品事实的唯一 owner。冲突时以本文件 + 用户最新决定为准。
> 名称为提案（理由：目标导向的"北极星"隐喻贯穿 UI 与 demo 叙事），可替换，替换不影响其余定义。

## 0. 一句话

**你说目标，AI 舰队替你研究、进化、执行。**
一个目标导向、自我进化、带硬风控闸门的自治交易副驾。默认全程模拟盘。

Demo 口号：*Set the star. The fleet sails.*

## 2. 目标用户与问题

- **主用户**：忙碌的闲钱投资者。有 $10k–$100k 闲钱、对美股感兴趣、没时间也没专业知识；身处 UTC+8 时，美股常规时段是深夜 21:30–04:00。核心时刻：**睡前 30 秒想知道"我的钱今天怎么样，明天打算干什么"**。
- **真实触发时刻**：发了工资想让闲钱干活；看别人晒单心痒；自己炒过亏了；听说"卖期权收租"但完全看不懂。
- **现有替代及其不满**：
  - 定投 ETF：省心但无参与感（诚实声明：它是强基线，系统内置与它的对比，敢比才可信）；
  - 跟单群/信号服务：黑箱、利益冲突、无风控；
  - 自学量化：半年起步的门槛；
  - 券商智能投顾：只做资产配置，不做策略，不解释。
- **价值承诺**：像雇了一支**透明的**量化小团队——你定目标，它出计划、跑经典策略、自我改进；每一步有人话解释、有硬护栏、有完整血缘可查。默认模拟盘，零风险体验全流程。
- 付款者=使用者=受益者（同一个人）。黑客松阶段不做商业化承诺；远期方向（订阅 SaaS）不在本轮冻结，转真实产品时需重过证据门。

## 3. 傻瓜化 ≠ 无脑：六条产品公理

1. **目标进，参数不进。** 用户输入"12 个月赚 15%"或"每月多 $500"，永远不填 delta、DTE、止损百分比。
2. **目标必须被诚实翻译。** 系统把目标翻译为：需要的年化收益 → 匹配的策略组合 → 该组合的历史回撤与**达成概率**（回测分布 + 蒙特卡洛，标注为估计）。反馈分三档：稳健可达（绿）/ 需承担较高风险（黄，明说回撤代价）/ **不现实（红，直说，并给出最近可达的替代：延长期限或降低目标）**。绝不出现收益承诺。
3. **风控是推导产物，不是用户作业。** 止盈/止损/仓位/集中度从目标与风险档自动推导为默认值；用户可在护栏内调滑块；越出护栏需要显式确认（"我理解最坏可能亏 $X"）。"只设置赔多少"不再是用户要做的事，是系统替用户算出的产出。
4. **每笔交易一句人话 + 一个为什么。** 例："卖出 NVDA 3 月 $175 看跌期权，收 $230 权利金——相当于愿意在 $175 接货；当前价 $196，缓冲 10.7%。"
5. **渐进披露。** 默认极简（目标进度 + 今天发生了什么）；点开有专业面板（希腊字母、回测细节、完整血缘）。简单是表面，专业是底层，全程可下钻。
6. **护栏是代码，不是提示词。**（借自 hermes-trader 的原则）任何 LLM 输出都过不了确定性闸门以外的路径；LLM 的工具清单里没有下单。

## 4. 用户主路径

**Path A · 设定与启动**（首次，约 5 分钟）
目标（金额+期限，或月收入目标）→ 3 个风险问题（卡片单选）→ **计划提案屏**（达成概率仪表 + 最大回撤预告 + 策略组合构成 + 与"定投 SPY"基线对比）→ 一键启动（默认模拟盘，PAPER 徽章教育）。
失败路径：目标不现实 → 红色诚实反馈 + 两个替代方案，不允许"硬来"。

**Path B · 日常查看**（高频，30 秒）
打开驾驶舱 → 目标进度 → "今日舰队日报"三句人话 → 关掉睡觉。

**Path C · 决策时刻**（低频；用户唯一需要动手的三种时刻）
1. 批准/忽略策略晋级（进化循环产出挑战者）；
2. 确认超护栏调整（用户自己想加仓/改目标时）；
3. 模拟→实盘毕业确认（黑客松版本永不出现，此项 disabled 并诚实标注）。
所有审批有超时，超时=默认拒绝。

**Path D · 进化陈列室**（兴趣驱动）
看策略族谱（v1→v1.2→v2）、每代的假设与样本外证据、AI 研究员的实验报告。

**失败与恢复（一等公民）**：断路器触发 → 全局红条（原因 + 已暂停范围 + 恢复条件 + 人工恢复按钮）；数据断流 → 降级为只读并声明；审批超时 → 拒绝并通知。

## 5. 开箱经典策略目录（v1 = 14 个，用户可自选，默认由计划组合）

> Alpaca 赛规要求所有策略含期权 → 提交系统以期权策略为主力；默认组合必含期权策略。
> 每个策略是**确定性规则程序**（可回测、可审计），带：人话一句、机制说明、适用环境、风险档、最小资金、Alpaca 期权等级要求、默认参数与护栏范围。

**期权类（8）** — 全部 defined-risk 或有担保：
| 策略 | 人话 | 风险档 | Alpaca 等级 |
|---|---|---|---|
| Wheel 轮动收租 | 卖保险收租金：现金担保卖权→被指派接货→备兑卖购，循环 | 中低 | L1 |
| Cash-Secured Put | 愿意低价接货，先收权利金 | 中低 | L1 |
| Covered Call | 持股出租，收租降成本 | 低 | L1 |
| Bull Put Credit Spread | 看不跌，收权利金，亏损封顶 | 中 | L3 |
| Bear Call Credit Spread | 看不涨，收权利金，亏损封顶 | 中 | L3 |
| Bull Call Debit Spread | 花小钱看涨一段，收益亏损都封顶 | 中 | L3 |
| Iron Condor | 赌横盘，两边收租，亏损封顶 | 中 | L3 |
| Protective Put | 给持仓买保险 | 低 | L2 |

**股票类（6）**：动量轮动 Top-N、双均线趋势跟踪、RSI 均值回归、布林带回归、板块轮动、防御配置（60/40 型，兼作内部基线）。

**禁止项（写进编译器与闸门）**：裸卖未担保期权、市价单、开仓 DTE < 7、0DTE、单标的集中度 > 20%。

## 6. 进化循环（Hermes 式自我迭代，走常规量化流程）

```
提议 propose → 回测 backtest → 评分 score → 模拟盘试运行 paper trial → 晋级/归档 promote/archive → 沉淀 library
      ↑__________________________ 多臂老虎机式选择下一个探索方向（RD-Agent 模式简化版）__________________________|
```

| 步骤 | 执行者 | 输入→输出 | 门槛 |
|---|---|---|---|
| 提议 | **Gemini**（唯一 LLM 环节） | 市场环境+现有策略表现+因子库 → 参数变体/因子假设（结构化 `EvolutionExperiment`） | 每轮变体数上限（防 p-hacking） |
| 回测 | 确定性代码 | 假设 → walk-forward 回测报告（含成本模型） | 样本外窗口强制保留 |
| 评分 | 确定性代码 | 回测报告 → 统一评分卡（净收益/最大回撤/Sharpe/胜率/尾部） | 样本外 Sharpe ≥ 现任×1.1 且回撤≤护栏（数值待校准） |
| 模拟盘试运行 | 执行引擎（小额） | 通过者上 paper 队伍跑真实行情 | 黑客松 1–2 天；产品态 2–4 周；审计 plan-vs-execution 偏差 |
| 晋级/归档 | **代码闸门 + 人一键确认（HITL）** | 试运行证据 → 晋级为可选策略 / 归档带失败原因 | 晋级门是代码不是 LLM |
| 沉淀 | 策略库 | 完整血缘：假设→回测→模拟盘证据→版本号 | 同一事实一个 owner |

**防过拟合底线（专业红线）**：walk-forward 切分；样本外保留不参与调参；记录每族试验次数（多重检验意识）；最小样本长度；成本与滑点模型；同族参数变体数量上限。
**用户视角叙事**："本周 AI 团队试了 7 个想法，2 个过了回测，1 个在模拟盘跑赢现任，已上架待你确认。"

## 7. 成功信号

- **黑客松**：(G) 评委能自己打开 demo 完成 Path A+B；5 分钟视频讲清端到端。(A) 比赛窗口正 P&L；write-up 完整；进化族谱图成为传播点。
- **产品态（远期，全部标注为待校准假设）**：模拟→实盘转化率、周查看留存、目标达成率 vs 基线。

## 8. 非目标（v1 明确不做）

真钱实盘（全程模拟盘 $100k）；0DTE/日内高频；自定义策略编辑器（Composer 式 no-code builder 是远期方向）；社交/跟单；多账户与团队；移动原生 App；税务/出入金；AlpacaTradingAgent 全量集成（列为可选增强，见 TECH.md D6）。

## 9. 关键假设与失效条件

1. **LLM 提议能产生样本外改进** — 进化循环用数据回答；若失效，进化循环退化为参数网格搜索，产品仍成立（叙事改为"系统化实验室"）。
2. **约 5 天 P&L 窗口有运气成分** — 对策：主仓 premium-selling（稳定现金流）+ 小仓方向性（博排名弹性）；若市场剧烈波动触发断路器，叙事转为"风控保住了本金"（这本身是合格的 demo 故事）。
3. **达成概率来自历史分布** — 永远标注为估计，非承诺。
4. **期权回测受数据边界约束**（Alpaca 期权历史数据自 2024-02 起）— 处理方式见 TECH.md D3。

## 10. 重新打开条件

比赛结束转真实产品时：商业定义（谁付费买什么）需重过证据门；实盘上钱需完整走 TECH.md 附录的高风险执行清单（毕业闸门、独立复核、最小授权），本轮一律不执行。
